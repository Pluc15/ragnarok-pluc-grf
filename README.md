# Pluc RO Tools

## Description

A collection of tools, configurations, and GRF edits to enhance and customize the Ragnarok Online client experience. This repository includes visual tweaks, quality-of-life improvements, and utilities for easier setup and maintenance.

- Replace Emp, Barricade, and Flag sprites
- Identify flag destinations and spawn areas
- Add missing minimaps with details
- Add label above MVP tombs
- Enlarge MVP sprites
- Enlarge Incubus and Succubus sprites
- Make status effects visible
- Add Acid Demonstration effect
- Replace Dispell effect
- Replace Emergency Call effect
- Select skill level in UI
- Hide skill names not useful for WoE
- Make Sniper arrows visible
- Remove jokes, scream, and pet messages
- Remove camera angle restrictions
- Hide headgears
- Add Pneuma timer
- Reduce song audio duration
- Improve LGP visuals
- Enable grey world (quadrant map not yet implemented)
- Remove loading screens
- Disable manners filter
- ...and more
